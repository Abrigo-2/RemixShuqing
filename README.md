This mod adds the following changes to the Shuqing campaign:
- A custom worldstate! Farm Arrays is disconnected from (almost) all regions, and most spawns have been replaced with creatures more difficult for the Shuqing.
- Shuqing's campaign properties have been remixed! They need more food and have been made omnivorous, still leaning toward carnivorous.
- Farm Arrays connects with the modded region "Southwest Exit"! There's not much reason for this. I just like the region and thought it was fun to play it as the Shuqing.

These aren't all the changes! Everything that couldn't be done without code is located at [the DLL Repository](https://github.com/Abrigo-2/RemixShuqing-DLL).
